# Quake Friends

Закрытая браузерная комната Quake III Arena на пользовательских игровых архивах.
Публичная комната: https://201.34.158.52/ (HTTPS, до 12 игроков).
Локальный прототип: http://localhost:8088/ — работает только на компьютере, где запущен сервер.

В репозитории только исходный код. Игровые PK3, локальные пароли, SSH-ключи и
личный `q.cfg` не публикуются. Для собственного запуска сначала выполните
раздел «Сборка с нуля» со своими файлами Quake III. Без них шесть выбранных карт
не будут доступны. `q.cfg` необязателен: если добавить его в
`public/assets/baseq3/`, он выполнится только по команде `exec q.cfg` в игре.

## Открыть и играть

1. Откройте START.cmd (если сервер уже запущен, повторный экземпляр не создаётся).
2. На странице введите ник латиницей и пароль из runtime/settings.json.
3. При первом запуске прочитайте показанное игрой соглашение и подтвердите согласие.
4. Дождитесь загрузки примерно 140 МБ. Нажмите на игру, чтобы захватить мышь.

WASD — движение, мышь — прицел / выстрел, пробел — прыжок,
цифры / колесо — оружие, Tab — счёт, T — чат, Esc — меню.
Полный экран включается кнопкой над игрой.

Изначально общая карта PRO-Q3TOURNEY4, каждый за себя, 20 фрагов / 15 минут, до 12 участников.
Ботов на сервере нет: матч ждёт живых игроков.
Доступны шесть выбранных карт: PRO-Q3TOURNEY4, PRO-Q3DM6, ZTN3TOURNEY1, Q3DM17, Q3DM13 и Q3DM19.
Карту, режим и лимиты меняет администратор через /admin; все игроки находятся на одной карте.
Если игрок выбирает «Новая игра» в меню Quake, запускается одиночная локальная партия. Для общей комнаты нужно вернуться на главную страницу и нажать кнопку входа.

## Админ-панель

Откройте https://201.34.158.52/admin и введите отдельный админский пароль
из runtime/settings.json (поле adminPassword). Пароль комнаты здесь не подходит.
Выберите карту, режим, максимум игроков (2–12), время (1–120 минут)
и лимит фрагов (1–100). Для CTF тот же лимит означает количество захватов флага.
Список карт автоматически ограничен теми, которые подходят выбранному режиму.
Кнопка «Применить и перезапустить» сохраняет настройки в runtime/match.json,
завершает текущую партию и пересоздаёт только игровой процесс. Участникам нужно
вернуться на главную страницу и снова войти в игру. Пароль комнаты сохраняется.
Админский пароль создаётся при первом запуске версии с панелью; его можно
заменить в settings.json и перезапустить службу quake-friends.
Админ-панель показывает только шесть оставленных карт. Их ресурсы собраны
в пять PK3 без музыки и лишних арен; tools/prune-assets.mjs и
tools/compact-assets.mjs воспроизводят облегчённую сборку.

STOP.cmd останавливает только процессы этой папки.
Пароль не встроен в страницу и не отправляется в ссылке.

## Сборка с нуля

Нужен Node.js 22.15+ (проверено на Node.js 24.18 / Windows).

    npm ci --ignore-scripts
    npm run setup
    npm run full:import -- "ПУТЬ-К-ПОЛНОЙ-ИГРЕ\baseq3\pak0.pk3"
    node tools/prune-assets.mjs
    node tools/compact-assets.mjs
    node tools/activate-curated.mjs
    npm start

Перед тремя командами сборки скопируйте ztn3tourney1.pk3 из своей папки Quake III в vendor/.

Setup скачивает два зафиксированных движка JavaScript и официальные установщики
демоверсии / point release из зеркала. Установщики не выполняются:
из них извлекаются только перечисленные игровые файлы.
Проверяются SHA-256 и CRC32. Бесплатный demo pak0 при сборке заменяется пользовательским архивом полной версии.

Для исходной полной сборки архив разделяется на браузерные пакеты.
В облегчённой сборке сохранены только шесть выбранных карт, а общие текстуры,
модели и звуки объединены в пять PK3 без изменения содержимого файлов.
Видеоролики кампании не нужны общей сетевой комнате и пропускаются.
После импорта копия пользовательского архива сохраняется в vendor/retail-pak0.pk3
и повторное npm run setup снова собирает полную версию. Архив не входит в Git.
На VPS загружена готовая облегчённая сборка; исходные PK3 сохранены в runtime/full-backup для возврата к полной версии и повторной сборки.
Остальные файлы, включая q3key, переносить не нужно.

## Проверка

При работающем приложении:

    npm test

Проверяются закрытый доступ к движку и файлам, вход по паролю, cookie,
запрет стороннего Origin и защита WebSocket.
tools/multiplayer-qa.mjs — дополнительная проверка в Playwright с двумя
независимыми браузерными сессиями; требует установленного Playwright и Edge.
Отчёт и снимки находятся в test-output (не публикуются).

## Размещение на Ubuntu

Комната работает на Ubuntu 24.04 по адресу https://201.34.158.52/.
Файлы размещены в /opt/quake-friends; служба systemd называется
quake-friends.service. Для проверки и перезапуска:

    systemctl status quake-friends
    systemctl restart quake-friends
    journalctl -u quake-friends -n 100
    tail -n 100 /opt/quake-friends/runtime/game.log

Nginx принимает только внешние HTTP/HTTPS на портах 80/443.
HTTP перенаправляет на HTTPS. Игровой Node и WebSocket слушают только
127.0.0.1:8088 и 127.0.0.1:27960, соответственно.
Публичный сертификат на IP выдаёт Let's Encrypt; его короткий срок
компенсирует ежедневная проверка таймером quake-friends-certbot.timer.
Пробное продление проверено. Ключ SSH для обслуживания хранится только
локально в runtime/deploy_ed25519 и не включён в сборку.

Развёртывание повторяется через deploy/make-bundle.py,
deploy/upload-parallel.py и скрипты deploy/install-*.sh.
Пароль комнаты хранится в runtime/settings.json и на сервере доступен
только учётной записи игры.

## Происхождение и лицензии

Это оболочка и частный сервер поверх QuakeJS, а не новый движок с нуля.
Пользовательский архив полной Quake III хранится локально в vendor/retail-pak0.pk3 и не включается в Git.
Демофайлы и point release сохраняют исходные лицензии id Software:
public/licenses/quake3-demo.txt и quake3-patch.txt.

- QuakeJS: https://github.com/inolen/quakejs/tree/977b188e05b239b6c48d7ecda9d04e9ca03f1578
- Движок ioq3: https://github.com/inolen/ioq3/tree/4f7d7bf (GPLv2).
- Клиент и зеркало демоданных: https://github.com/mcftira/quakejs/tree/301663bb60e292ee011bb0520ac22b5d5eaeab55
- Контрольные суммы: vendor/sources.json.
- Все изменения скомпилированных движков воспроизводятся в tools/prepare.mjs:
  современный ws API, уникальные транспортные порты, защищённый same-origin
  WebSocket и загрузка файлов с того же хоста. Оболочка выдаёт отдельный net_qport
  на каждый запуск клиента, чтобы несколько друзей за одним адресом не конфликтовали.

Проверен запуск всех шести выбранных карт. PRO-Q3TOURNEY4 и ZTN3TOURNEY1 также загружены в чистом браузере.
